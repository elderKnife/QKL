## 复现命令

```bash
cd /home/blockchain/fisco-bcos-lab

# 启动五节点（需授权绑定本地端口）
bash nodes/127.0.0.1/start_all.sh

# 实验 A
python3 -m src.run_all A

# 实验 B
python3 -m src.run_all B

# 全部
python3 -m src.run_all all
```

重复运行会生成新的唯一 batchId，不会覆盖已有链上记录。
