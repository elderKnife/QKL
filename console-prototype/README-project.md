# FISCO BCOS 可信存证实验：学生开发交接包
整理日期：2026-11-03（Asia/Shanghai）

本包供阅读、借鉴与后续开发。保留实验源码原貌，未修复审查发现的问题，不是开箱即用的部署包，也不是完整链环境备份。

本次另外加入一套独立的 Go + Docker Compose 边缘轻节点/VPP 本地原型，见 [原型说明](README-edge-prototype.md)。设备、边缘、VPP 和全量数据持久化使用 Go 与 MySQL；模拟链摘要不是 FISCO BCOS，也不表示新增实现已接入真实链。历史实验 A/B 的 `src/` 与合约来源文件保持未改动。

本原型现在包含本机免登录 Web 操作台，支持运行总览、记录与批次查询、模拟采集控制和 VPP 本地重新核验；使用说明见 [Web 操作台指南](README-web-console.md)。默认地址为 `http://127.0.0.1:18082`。页面明确标识模拟设备与模拟登记，不是 GRID 或真实链验收。

## 目录
- src/：10 个原始 Python 文件。主入口 run_all.py；核心流程 experiment_a.py、experiment_b.py。
- contracts/：原始合约及本地 ABI/bin。编译产物作为参考保留，不证明已部署版本。
- data/：原始模拟业务数据和签名样本。
- examples/historical/A、B/：各一组历史样例、白名单摘录的证据摘要和回执。
- docs/：本次新编写的交接与开发说明。
- reference/：原始说明文档存档；其中的历史验收结论、运行命令和旧链接需要结合新说明阅读。
- MANIFEST.json：文件来源和 SHA-256；不包含自身哈希。

## 执行前必须知道
原入口会创建结果目录、生成或加载密钥、调用链发送交易。不要在导师原实验环境直接执行。
源码保留旧的绝对路径、账户地址、合约地址；学生须先在独立副本中完成配置外置及环境隔离。
现有 chain.py 的按端口查询封装也会写运行配置，不能作为无副作用的只读查询工具。
本包没有任何账户私钥、SDK 私钥、节点密钥、业务私钥或访问令牌；学生应使用自己的测试身份。
包内公钥、业务签名、地址及交易哈希是历史参考信息，不是可信身份配置。
本次整理没有运行实验、部署合约或发送交易，也没有重新核验在线链状态。
