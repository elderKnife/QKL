# 环境与复现前提
## 历史观察，不能当锁定依赖
- 本机检查：Python 3.10.12、cryptography 3.4.8、OpenJDK 17.0.20.1。
- Console JAR 版本常量：3.7.0；随包 Java SDK/JNI JAR 文件名标注 3.7.0。
- 原节点配置声明：FISCO BCOS Air 3.16.4、chain0/group0、PBFT、非国密；二进制有 3.16.4 字符串。
- 原 SDK RPC 配置：127.0.0.1:20200–20204。
- 未重新核验在线节点版本、运行配置、账本状态或合约代码；本包不承诺上述组合在干净环境可直接复现。
- 未发现 requirements/pyproject/锁文件。cryptography 是源码中主要第三方 Python 直接依赖；应由开发团队在独立环境选择并验证版本，不把旧版观察值直接当成安全或兼容推荐。

## 独立环境需准备
1. 单独工作目录/虚拟环境，安装团队选定且验证的 Python 依赖。
2. 官方可信来源的 FISCO BCOS、Console 和配套 Java/SDK；本包未附大型二进制与 JAR。
3. 独立测试链及自己的节点/SDK 证书、交易账户和业务密钥；不要借用导师现有私钥。
4. 修正源码中的绝对路径、合约/账户地址与 RPC 配置；隔离输出和密钥目录。
5. 对修订后的合约重新完成编译与部署验证，保存编译器、优化选项、源码/产物哈希和部署回执。
6. 先做离线算法与异常处理验证，再在获准的测试链进行集成。

## 原入口说明
原包通过 python3 -m src.run_all A/B/all 选择实验，此处仅解释入口，不作为立即执行指令。
直接执行会写文件、生成/读取密钥和发送交易。
sample_trace.py 含在线查询与写出；chain.py 按端口查询含配置写入。
本包缺少运行环境和凭据，不应被描述为解压即用的完整系统。
