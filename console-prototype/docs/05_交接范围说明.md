# 交接范围说明
## 保留与新增
src/、contracts/、data/ 和 reference/ 内的文件来自原项目白名单，逐字节保留，来源和 SHA-256 见 MANIFEST.json。
docs/ 与根 README.md 为本次交接新增说明，不代表已修改实验实现。
examples/historical/ 的 summary.json 和 receipt_selected.json 是从历史输出按明确字段摘录的新文件；不是原始日志、不是新回执，也不是完整证据链。

## 排除内容
整个 console/、nodes/、runtime/、backup/、隐藏配置目录、.git、编辑器设置、缓存、大型链二进制/安装包、原始日志及全量 output/ 均未打包。
特别排除全部账户/业务/节点/SDK/CA 私钥、证书文件及账号凭据。未读取原项目私钥内容。
原始 console 配置和运行目录没有复制；源码中仍有用于理解旧实验的非敏感地址和路径。

## 历史样例边界
A/B 各选按目录运行标记最新的一组，均只有三条样例。
原始主交易记录的状态为 0，A 回执与报告高度均为 9，B 均为 10；本地重算根与两节点历史查询记录一致。
B 原始转发记录有交易哈希和两节点查询，但没有独立完整回执；本包不补造回执。
保存的签名使用样例随附公钥可验，但该公钥不是预置信任锚；历史签名不应作为新指令执行。
reference/ 中原文档描述历史验收与旧目录链接，不保证其相对链接在本交接包有效；当前判断以新 docs/ 为准。
历史输出只证明文件记载相应结果，本次没有重新验证在线链状态。

## 校验与交接
ZIP 同目录的 .sha256 保存压缩包 SHA-256。Windows 接收方可用 PowerShell 的 Get-FileHash 核对 ZIP。
解压后先看根 README.md。建议将此交接包作为新的开发基线，另建受控代码仓库；账户、密钥、环境配置和数据库文件不入库。
