证明问题的边界：当前验证器仍会检验记录摘要是否沿给定路径到达期望根；发现的是身份、位置与树结构元数据未受完整约束，不等于已经证明可以伪造任意记录内容。

合约 getBatch 不存在记录时返回空字符串与零。timestamp 是调用参数，不是区块时间。无显式修改、删除或权限管理接口；空编号覆盖为例外。成功有事件与 true 返回值；非空编号重复有回滚消息。

本地源码及多份 ABI/bin 分别一致，历史交易 input 与当前编码兼容；但缺少部署交易、可复现编译和当前运行时代码的完整对应核验，不能把当前源码直接认定为已部署版本。
原文档关于 EDGE 独立核验的描述比实际实现更强，应按上述源码事实修订。
